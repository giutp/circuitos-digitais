## 📂 Projetos

| Projeto | Descrição | Conceitos |
|---------|-----------|-----------|
| [⚙️ ALU](./ALU) | Unidade Lógico-Aritmética de 6 bits: soma, subtração, multiplicação e comparação de igualdade | Circuitos combinacionais, somadores, complemento de dois, multiplexadores |
| [🚦 Sincronização de Semáforos](./Sincronização-Semáfaros) | Máquinas de estados sequenciais com flip-flops D/S-R/J-K para simular semáforos com botão de pedestre | FSM, flip-flops, tabelas-verdade, mapas de Karnaugh |
